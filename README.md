# xcoreCli

xcore runtime CLI for dev

## About

This is the xcore runtime command-line interface designed for developers to interact with and manage xcore runtime applications.

## Language

- **Python** 100%

## Getting Started

### Prerequisites

- Python 3.x

### Installation

```bash
git clone https://github.com/xcore-team/xcoreCli.git
cd xcoreCli
```

### Usage

```bash
python -m xcoreCli [command] [options]
```
